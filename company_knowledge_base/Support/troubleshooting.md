# Common Troubleshooting Guide
For API authentication failures, verify token validity, token scope, and account permissions.

For rate-limit errors, check the API response and reduce request frequency or contact the account owner about an increased limit.

For delayed workflow execution, check workflow status, recent deployments, queue health, and retry information.

For dashboard data discrepancies, verify the report time range, filters, data refresh status, and source system synchronization.

If troubleshooting does not resolve the issue, create an escalation with the relevant evidence.
