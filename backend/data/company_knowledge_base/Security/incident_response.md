# Security Incident Response
A security incident may include unauthorized access, suspected credential compromise, malware, data exposure, or loss of a company device.

Employees should report suspected incidents to the Information Security team immediately and should not attempt to hide or independently investigate a serious security event.

The security response process includes detection, containment, investigation, remediation, recovery, and post-incident review.

Incident details should only be shared with people who need the information to perform their responsibilities.
